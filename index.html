03. Projects

Final Year Project · 82%

SkySpot: Drone Car Park Occupancy

A drone that surveys MTU's Bishopstown car park and reports which spaces are free, with a web and Android app that shows drivers a live map, a forecast and an AI assistant. Built in a team of three.

My part: the edge AI and the occupancy algorithm.

  • Trained a single-class YOLOv8s detector on the VisDrone aerial dataset, exported it to ONNX and compiled it with the Hailo Dataflow Compiler for a Hailo-8 on a Raspberry Pi 5.
  • Wrote the Python occupancy algorithm. It projects GeoJSON-mapped bays into each frame from camera geometry and PX4 telemetry (GPS, altitude, heading), aligns them to detections with a coarse-to-fine search, and assigns each car to one bay by exclusive nearest-neighbour matching.
  • Rejected unusable frames by altitude, roll, pitch and heading change, and smoothed per-bay results with an exponential moving average that resets on turns.
  • Validated on five real flights; the final version identified 5 of 5 target vacant spaces.
  • Python
  • YOLOv8s
  • OpenCV
  • ONNX
  • Hailo-8
  • Raspberry Pi 5
  • PX4
  • React
  • FastAPI
  • Azure

The rest of the system:

  • Holybro X500 V2 frame with a Pixhawk 6C flight controller and M10 GPS, flying repeatable waypoint missions planned in QGroundControl.
  • React and FastAPI web app with a native Android app, deployed as a Docker image on Azure Container Apps.
  • Occupancy forecast trained in Azure AutoML on about 26,000 hourly records with time, weather and calendar features (R² 0.984).
  • "Sally", an Azure OpenAI assistant driven by n8n workflows, answers questions like "How many bays are free right now?"
  • Accessibility settings for text size, readable fonts and colour-vision filters.

MTU Prize for Innovation · Best Pitch

Headstrong: MND Neck Support

An adaptive neck support collar for people living with Motor Neurone Disease, who gradually lose the neck strength to hold their head up. It won Best Pitch at the MTU Prize for Innovation 2025.

My part: I came up with the idea of supporting the head with inflation, researched the materials, did the electronics and helped write and deliver the pitch.

  • The collar is built from a ring of inflatable tubes divided into sections: front, back, left and right. Each section inflates or deflates on its own to support the head where it is needed.
  • It starts with a simple self-inflating valve. As the disease progresses, a unit with an air pump takes over, so support grows with the user's needs.
  • From my materials research: TPU (thermoplastic polyurethane) tubes for flexibility and puncture resistance, under a Tencel cover that is soft, moisture-wicking, hypoallergenic and resistant to bacteria, which suits users who spend long periods in one position.

Security Penetration Testing

Penetration Test Report

A full penetration test in two parts: OSINT reconnaissance against a large real-world organisation, then active scanning and exploitation of two vulnerable machines on an isolated VirtualBox lab network.

  • Reconnaissance: passive OSINT only, using theHarvester, Sublist3r, Knockpy, WhatWeb, Recon-ng, Shodan and SpiderFoot. Mapped 180 subdomains and 112 IP addresses, mapped the findings to MITRE ATT&CK and made defensive recommendations.
  • Metasploitable 2 (Linux): scanned with Nmap and Nessus, then got root through the vsftpd 2.3.4 and UnrealIRCd backdoors and recovered /etc/shadow.
  • Metasploitable 3 (Windows Server 2008 R2): SYSTEM access via EternalBlue (MS17-010). Dumped 20 NTLM hashes, then chained harvested credentials into a Tomcat Manager WAR upload for a second SYSTEM shell.
  • Wrote prioritised remediation for each target: patching, least privilege, MFA and secrets management.

Book Recommendation App

A web app that tackles "what should I read next?" by combining a user's own star ratings with book metadata. We built it in Scrum sprints, and I was Scrum Master for Sprint 1.

Raspberry Pi Edge-to-Cloud IoT

A series of IoT labs that collect, process and sync data between Raspberry Pis at the edge and the cloud.

  • Sensor monitoring: IOTstack (Docker) on two Pis, with DHT11 temperature and humidity readings going over MQTT into PostgreSQL and InfluxDB, and Node-RED, Flask and Grafana on top. Fast temperature alarms (>50 °C within 100 ms) run at the edge, and sustained-humidity warnings run in the cloud.
  • InfluxDB: Telegraf logs Pi health data (CPU temperature, Mosquitto and Node-RED status) to a local InfluxDB, which replicates it to Azure InfluxDB SaaS.
  • PostgreSQL: logical replication of a users table from a cloud database to the Pi.
  • Final project: two NiceGUI single-page apps. One is a user management app (insert, update, soft and hard delete) hosted on Azure Container Apps. The other is an offline login app on the Pi that launches in Chromium kiosk mode at boot through systemd.
